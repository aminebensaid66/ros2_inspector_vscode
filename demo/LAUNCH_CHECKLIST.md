# Public launch checklist

Do not publish or announce the Marketplace release until every required item below is complete.

## Repository

- [ ] Run `npm install` on a machine with npm access and commit the generated `package-lock.json`.
- [ ] Run `npm run verify`.
- [ ] Install `ros2inspector==0.1.3` and run `npm run test:real`.
- [ ] Create/push the repository with `scripts/bootstrap-github.sh`.
- [ ] Confirm GitHub CI is green on Ubuntu, macOS and Windows.
- [ ] Confirm the VS Code Electron extension-host job is green.
- [ ] Download the CI-generated VSIX and install it into a clean VS Code profile.

## Manual VS Code acceptance

- [ ] Missing analyzer produces Setup Help instead of a crash.
- [ ] `pipx`/PATH analyzer discovery works on macOS/Linux.
- [ ] Python / `py -3` fallback works on Windows.
- [ ] Activity Bar explorer scans a real ROS 2 workspace.
- [ ] Source Nodes and Deployments are shown separately.
- [ ] Topic/service/action items and source navigation work.
- [ ] Communications, Dependencies and Full graph modes work.
- [ ] Search, pan, zoom, Fit and details work.
- [ ] Large graph truncation is explicitly reported.
- [ ] Problems diagnostics point to the correct source file/line.
- [ ] Policy validation handles both clean and violating policies.
- [ ] Untrusted workspace does not execute the analyzer.
- [ ] WSL / Remote SSH / Dev Container smoke test completed if available.

## Marketplace

- [ ] Create/verify a Marketplace publisher whose ID is exactly `aminebensaid66`, or update `package.json#publisher` to the real publisher ID.
- [ ] `npx @vscode/vsce ls` contains only intended files.
- [ ] `npx @vscode/vsce package` succeeds.
- [ ] Marketplace listing renders README screenshots correctly.
- [ ] Privacy/security statements match actual behavior.

## Launch media

- [ ] Use `media/product-preview.png` as the hero image.
- [ ] Attach `demo/ros2-inspector-vscode.mp4` to LinkedIn when video upload is available; otherwise use the GIF/screenshots.
- [ ] Keep the wording clear that the VS Code shell previews are presentation composites, while the graph states are generated by the actual renderer.
