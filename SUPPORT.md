# Support

For extension bugs, include extension version, `ros2inspector --version`, VS Code version, OS/remote environment, the selected workspace, and relevant **ROS2 Inspector** Output logs.

For ROS parsing, inferred architecture, audit semantics, or policy-rule correctness, report the issue in the core ROS2 Inspector project; this extension deliberately does not reimplement those semantics.

The extension is static-only and does not troubleshoot a live ROS graph.
